# Architecture

## Configuration source graph

`hypr/.config/hypr/hyprland.lua` is the entry point. It sets monitors, exports
environment, configures input and gestures, then requires six modules:

```text
hyprland.lua
├── conf/variables.lua       terminal, browser, file manager, disks, scripts_dir
├── conf/keybindings.lua     every keyboard and mouse binding
├── conf/window_rules.lua    floating behaviour, workspace assignment
├── conf/autostart.lua       the hyprland.start process list
├── conf/decorations.lua     GENERATED by the theme tool
├── monitors.lua             GENERATED machine state
└── workspaces.lua           GENERATED machine state
```

The last three are derived. `theme set` rewrites `decorations.lua`;
`auto-monitor-profile.sh` rewrites the monitor pair. Durable customization does
not belong in any of them — see [Customization](Customization.md).

`hyprland.conf` and its `conf/*.conf` siblings are a complete parallel hyprlang
graph, kept from the migration as a rollback path. Hyprland loads the Lua tree
(`[cfg] Using lua config found at .../hyprland.lua`), which is why `nwg-displays`
output written to `monitors.conf` has no effect.

## What `hyprland.lua` sets directly

- A permissive fallback monitor (`output = ""`, `mode = "preferred"`,
  `position = "auto"`, `scale = 1`) before `monitors.lua` narrows it.
- `XCURSOR_SIZE` and `HYPRCURSOR_SIZE` at 24. No cursor *theme* is tracked.
- `AQ_NO_ATOMIC=1`, flagged in-file as a workaround for an Aquamarine hotplug
  crash, to be removed once the page-flip bug is fixed.
- `no_hardware_cursors = 1`, similarly flagged, for rotated-output glitches.
- `PATH` prepended with `~/.local/bin` when it is missing. greetd's
  `start-hyprland` never sources `~/.zshrc`, so without this every Stow package's
  entry point would be unreachable from a binding. `hl.env` runs before the
  display server initialises, so this applies at next login, not on `hyprctl
  reload`.
- The night-light screen shader, enabled when
  `$XDG_STATE_HOME/hyprland-desktop/night-light-shader` exists.
- US layout, `follow_mouse = 1`, sensitivity `0`, touchpad natural scroll off.
- A three-finger horizontal workspace gesture.

Tap-to-click, repeat rate, keyboard variant, and keyboard options are not set
anywhere in the repository.

## Runtime process graph

```text
Hyprland `hyprland.start`
├── quickshell
│   ├── bar and workspace cells
│   ├── dashboard / network / audio / media / display / Bluetooth panels
│   ├── freedesktop notification service
│   ├── cliphist browser
│   ├── video-download OSD
│   ├── theme picker and wallpaper panel
│   └── desktop-mode panel and observed-state indicators
├── quickshell -c cava-visualizer
├── wl-paste watchers (text + image) → clipboard-store.sh → cliphist
├── hypr-wallpaper-picker restore → hyprpaper
├── hypridle → ASCII screensaver → conditional lock → DPMS → suspend
├── desktop-mode daemon → timed mode expiry and backend reconciliation
├── hyprsunset ← night-light.sh / desktop-mode adapter
├── spotify-notify.sh ← playerctl
├── systemctl --user start hypr-monitor-watch.service
│       └── socket2 IPC → auto-monitor-profile.sh → monitors.lua/workspaces.lua
├── udiskie --automount --notify --no-tray
└── pinned applications: kitty(1) helium-browser(2) obsidian(3) t3code(4)
                         virt-manager(6) hermes(6) spotify(9)
```

Quickshell is the only bar. SwayNC and Noctalia have no startup call. The only
tracked systemd unit is `hypr-monitor-watch.service`; everything else is an
`hl.exec_cmd()` from `conf/autostart.lua`, and `systemctl` appears only as the
suspend action.

## Command and data flow

### Theme selection

```text
SUPER+CTRL+SHIFT+SPACE, the Display panel's THEME row, or `theme set <slug>`
        ↓
theme → hypr/.config/hypr/theme/generate.py (+ themelib.py)
        ↓
themes/<slug>/colors.toml validated (roles, 16 ANSI colours, WCAG AA contrast)
        ↓
13 templates rendered and installed atomically
        ↓
Hyprland · Quickshell · Kitty · Rofi · Hyprlock · Wofi · SwayNC ·
Noctalia · Zsh · Fastfetch · regreet
```

Every entry point is a front end. They all hand a slug to `theme set`, which
stays the single source of truth for what is active. A broken palette leaves the
previous theme running.

### Wallpaper search

```text
SUPER+SHIFT+W
        ↓
hypr-wallpaper-picker (no args) → toggles the Quickshell cover-flow panel
        ↓
index / search / apply / activate / current / restore / cleanup
        ├── local ~/Pictures/wallpapers filename matches, first page
        └── SFW wallhaven.cc results ≥1920×1080, after local results
        ↓
download → ImageMagick validation → restart hyprpaper → apply in cover mode
        ↓
atomic write to $XDG_STATE_HOME/hyprland-desktop/wallpaper/current
```

Autostart's `restore` reads that state file. Missing or stale state starts plain
Hyprpaper rather than picking a fallback image. Hyprlock reads the same file
through the read-only `current` subcommand.

### Browser tools

```text
Chromium extension command (ALT+SHIFT+L or ALT+SHIFT+D)
        ↓
Chrome Native Messaging, host pinned to that exact extension ID
        ├── copy URL → wl-copy → the clipboard watcher records it
        └── download video → yt-dlp → Quickshell OSD → notification → mpv
```

### Windows VM

```text
SUPER+ALT+W, or the Windows.desktop entry
        ↓
windows-vm launch → Docker Compose → Dockur Windows → KVM
        ↓
"Windows VM started" notification, then a localhost RDP readiness probe
        ↓
FreeRDP fullscreen on the focused Hyprland monitor

SUPER+CTRL+ALT+W → windows-vm stop → graceful Compose stop → notification
```

RDP (3389) and the install viewer (8006) bind to `127.0.0.1` only. `~/Windows`
is the sole shared host directory. A clean RDP exit also stops the VM unless the
launch used `--keep-alive`.

## Active versus retained

| Component | Status | Evidence |
| --- | --- | --- |
| Quickshell | active | `hl.exec_cmd("quickshell")` in `conf/autostart.lua` |
| Hyprpaper, Hypridle, Hyprsunset | active | `conf/autostart.lua` |
| ASCII screensaver | on demand, and after 180 idle seconds without audio | `hypridle.conf` |
| desktop-mode daemon | active when the package is deployed | `conf/autostart.lua` |
| Rofi | active on demand | `SUPER+A` and helper scripts |
| Kitty | active default terminal | `conf/variables.lua` |
| SwayNC | retained | no startup call; line commented out |
| Wofi | retained | no binding, no startup |
| Noctalia | retained | no startup call; line commented out |
| Waybar | removed | recoverable from Git history |

This matters when debugging: editing SwayNC or Noctalia will not change anything
you can see.

## Environment variables

Set by Hyprland: `XCURSOR_SIZE`, `HYPRCURSOR_SIZE`, `AQ_NO_ATOMIC`, and `PATH`.

Honoured by scripts:

| Variable | Purpose / default |
| --- | --- |
| `HYPR_WALLPAPER_DIR` | wallpaper directory; `~/Pictures/wallpapers` |
| `HYPR_WALLPAPER_RUNTIME_DIR`, `HYPR_WALLPAPER_STATE_FILE` | picker runtime data and state path |
| `CHROMIUM_YTDLP_DIR` | browser video destination; `~/Videos` |
| `AI_AGENT_DEFAULT`, `AI_AGENT_CONFIG` | AI launcher default and config path |
| `DESKTOP_MODE_CONFIG`, `DESKTOP_MODE_RUNTIME_DIR` | mode config and fixture/runtime overrides |
| `ASCII_SCREENSAVER_CONFIG`, `ASCII_SCREENSAVER_MONITORS_JSON` | screensaver config and fixture monitor data |
| `SCREENSHOT_DIR`, `SCREENSHOT_EDITOR`, `SCREENRECORD_DIR`, `OCR_LANGS` | capture outputs and tooling |
| `LMENU_PARSER`, `ROFI`, `SYSTEMCTL`, `SYSTEMD_RUN` | lmenu overrides, mostly for its tests |
| `WEBAPP_BROWSER` | web-app launch browser, ahead of the built-in search order |
| `XDG_RUNTIME_DIR`, `XDG_STATE_HOME`, `XDG_CACHE_HOME` | locks, sockets, durable state, caches |
